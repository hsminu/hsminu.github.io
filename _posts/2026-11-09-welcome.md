배운 내용을 다시 꺼내 보고, 문제를 해결한 과정을 남기기 위해 블로그를 시작합니다.

## 어떤 내용을 기록하나요?

| 주제 | 기록할 내용 |
| --- | --- |
| [개발](/development/) | 프로젝트, 구현 과정, 문제 해결 |
| [CTF / Wargame](/ctf/) | 문제 풀이, 접근 방법, 대회 후기 |
| [Bug Bounty](/bug-bounty/) | 취약점 분석, 제보 기록 |
| [블로그 / 기술문서](/documentation/) | 개념 정리, 도구 사용법, 튜토리얼 |
| [논문 / 컨퍼런스](/research/) | 논문 리뷰, 발표와 참가 기록 |
| [공모전 / 자격증](/activities/) | 준비 과정, 공부 기록, 활동 후기 |

## 기록하는 방식

결과와 함께 **왜 그렇게 접근했는지**, **어디에서 막혔는지**, **무엇을 배웠는지**를 남기려고 합니다.

주제별 글은 왼쪽 메뉴에서, 특정 키워드는 검색과 [태그](/tags/)에서 찾아볼 수 있습니다.
